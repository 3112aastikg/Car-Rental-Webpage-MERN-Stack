# 🚗 Car Rental Web Application

A full-stack car rental platform built with the **MERN stack** as the final project for the Avaintern Full Stack Internship.

## ✨ Overview

The application allows users to:

- Browse available cars for rent
- View detailed information about vehicles
- Book cars for rental
- Add their own cars to the rental marketplace
- Share contact details so car owners and customers can communicate

The project includes separate frontend and backend applications and uses MongoDB for data storage.

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- HTML & CSS
- REST APIs
- Vite
- Vercel

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/3112aastikg/Car-Rental-Webpage-MERN-Stack.git
cd Car-Rental-Webpage-MERN-Stack
```

### 2. Install dependencies

Install dependencies in both the `client` and `server` directories:

```bash
cd client
npm install

cd ../server
npm install
```

### 3. Configure environment variables

Create the required `.env` file in the backend and add your MongoDB connection details and any other credentials required by the application.

### 4. Run the application

Start the backend and frontend according to the scripts defined in their respective `package.json` files.
